# V3.0 需求文档（摘自飞书）

"今天吃什么"微信小程序：根据已有菜品列表随机抽取菜品，并将结果加入我的饮食记录。
菜单分两大类：【我的菜谱·自己做】与【出去吃】，按分类随机抽取。

## 1. Tab
4 个 tab，悬浮形式常驻页面下方：【首页】【菜单】【添加】【我的】

## 2. 首页
- 2.1 分类两个按钮：【自己做】（默认选中）、【出去吃】
- 2.2 开奖池三态：
  - 待开奖：默认文案"今天吃什么"
  - 开奖中：菜名文案随机滚动
  - 开奖结果：显示具体菜名 + 呼吸灯动效，引导用户点击
- 2.3 【开始/停止】按钮：点开始按 2.1 选中分类取数；点停止按分类随机出结果
- 2.4 【勾选】按钮：点击代表 ok，跳转【我的】页并写入今日饮食记录

## 3. 菜单页
- 3.1 分【我的菜单】（默认）与【附近美食】两个一级导航
- 3.2 分类来自添加菜品的标签（同标签同类型），按字母顺序排列
- 3.3 分类区域下方悬浮【+】，点击跳转【添加】菜品页
- 3.4 菜品列表：
  - 同类型下按添加顺序排列
  - 单行显示：小图、菜名、菜名后显示用时（附近美食显示距离）、下方小标签
  - 点击整行 → 菜品详情页
  - 行末【+】按钮可选中/减选；附近美食显示【勾选】，点击代表 ok 并跳【我的】
  - 列表支持上下滑动
  - 列表下方悬浮：已加入几道菜 + 总需用时 +【开始吧】→ 跳【我的】

## 4. 添加页（= 添加菜品页 = 菜品详情页）
- 4.1 图片：默认【+】，支持拍照/上传图片
- 4.2 食材添加【+】，支持编辑当前菜有哪些食材
- 4.3 我的菜单做菜步骤【+/-】：每步一行，超长折叠、点击展开；行末显示该步用时，最后一行末显示总用时
- 4.4 左下方显示菜名；若从其他添加入口进入，优先以文本弹窗形式先编辑，支持点击二次编辑
- 4.5 菜名附近支持点击添加标签（如味道：酸甜苦辣；菜系：川、粤、淮、北…）
- 4.6 右下方悬浮【勾选】按钮，点击代表 ok，跳转【我的】页并写入今日饮食记录

> 补充：设计稿 ⑤（添加·附近美食）中的「地址 + 小地图 + 距离提示」在需求文档中未提及，
> 属设计稿单方面定义，已按设计稿实现。

## 5. 我的页
- 显示当前时间、年月日、周几
- 今日饮食：通过【勾选】按钮跳转此页，勾选的菜品加入今日饮食列表，显示菜名，可【+/-】
- 今日饮食指标：蔬菜、主食、蛋白质、水果
  - 文档明确说明：数据统计应来自详情页的食材，**具体算法待定**
